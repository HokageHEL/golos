## Git workflow

Make regular local Git commits at meaningful completed milestones, after running
the checks appropriate to the changes. Use descriptive commit messages and keep
unrelated user changes out of those commits.

After completing a task and passing the appropriate checks, push the changes,
open a pull request, and merge it into `main` on GitHub. This is standing user
authorization; do not ask for confirmation again for this workflow. Respect
branch protection and required checks, and report any blocker to merging.
